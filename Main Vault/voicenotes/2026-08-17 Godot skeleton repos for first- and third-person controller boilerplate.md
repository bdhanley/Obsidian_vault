# Godot skeleton repos for first- and third-person controller boilerplate

Date: 2026-08-17

## Transcript

So as part of my main work with Godot right now, I'm trying to create either one mono repo or a couple of repos. The idea is to have multiple skeleton projects that each control each contain the boilerplate needed for a particular control system. An example is one repo would be the skeleton code that would be able to scaffold a first-person game or another would be the skeleton code that would be able to scaffold a third-person game along the lines of Breath of the Wild or Dark Souls. 

The concept is building these to get the boilerplate out of the way and start having and being able to make more creative decisions and get into the meat of game design without having to worry about writing this constant, the same code over and over again and then getting bored. So I think that should be my first step and task is figuring that out. Basic collision, basic camera controls, basic Godot input handling, maybe just basic physics and exposing that to the editor.
